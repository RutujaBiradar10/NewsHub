# 📰 NewsHub – Real-Time News Web Application

A modern and responsive news application built with React.js that delivers real-time news across multiple categories. The project demonstrates React routing, API integration, state management, infinite scrolling, and responsive UI design.

## 🚀 Features

* 📰 Real-time news headlines from multiple categories
* 📂 Category-wise news filtering (Business, Sports, Technology, Health, Entertainment, Science)
* 🔄 Infinite scrolling for continuous content loading
* ⚡ Dynamic data fetching using REST APIs
* ⏳ Loading indicators for enhanced user experience
* 📱 Fully responsive design for desktop and mobile devices
* 🧭 Client-side routing using React Router

## 🛠️ Tech Stack

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3
* Bootstrap
* React Router
* NewsAPI
* Git & GitHub

## ⚠️ Note

This project uses the free NewsAPI Developer Plan. NewsAPI restricts requests from production domains and only allows requests from localhost. Therefore, live news data may not be visible on the deployed version, but the application works correctly in the local development environment.
