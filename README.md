📰 NewsHub – Real-Time News Web Application
A modern, responsive news application built with React that delivers real-time top headlines using the News API. The project demonstrates API integration, dynamic rendering, and infinite scrolling in a clean UI.

----

🚀 Live Demo
https://your-live-link.com
----
📌 Key Features
🔥 Real-time top headlines from trusted sources
📂 Category-based filtering (Business, Sports, Technology, Health, etc.)
🔄 Infinite scrolling for seamless browsing experience
⚡ Fast API data fetching with optimized state management
⏳ Loading spinner for better user experience
📱 Fully responsive design for mobile and desktop

----

🛠️ Tech Stack
React.js
JavaScript (ES6+)
HTML5
CSS3 / Bootstrap
News API
